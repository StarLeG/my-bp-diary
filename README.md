![License](https://img.shields.io/badge/license-MIT-green)
[![Тесты](https://github.com/StarLeG/my-bp-diary/actions/workflows/tests.yml/badge.svg)](https://github.com/StarLeG/my-bp-diary/actions/workflows/tests.yml)

Telegram-бот для ведения дневника измерений артериального давления: быстрая запись за
2 нажатия, напоминания о лекарствах, статистика и CSV для врача. Бесплатный, без рекламы.

- **Быстро**: запись давления — два нажатия кнопками, без свободного ввода.
- **Полезно для врача**: дневник, динамика, экспорт CSV за любой период.
- **С заботой**: напоминания об измерениях и лекарствах без спама и давления.

## Возможности

- **Запись давления** за 2 нажатия: систолическое/диастолическое/пульс кнопками
  (шаг 5, «Другое», «Пропустить»), самочувствие и заметка — по желанию.
- **Три замера в день** (утро / обед / вечер) с напоминаниями; после «Приняли лекарство?» →
  «Да» бот напомнит повторить замер через 30 / 60 / 120 минут.
- **Лекарства**: свой список с дозировками и слотами приёма, отметки «принял / пропустил»,
  приверженность «принято X из Y» в статистике.
- **Дневник**: история за сегодня / период, редактирование записей.
- **Статистика**: средние, мин/макс, тренд, сравнение с целью; экспорт CSV
  (измерения и приёмы лекарств) — чтобы показать врачу.
- **Личный кабинет** (с компьютера): история с фильтрами, график, CSV, лекарства,
  настройки напоминаний. Вход — по одноразовой ссылке из бота или e-mail + пароль.
- **Многопользовательность**: данные каждого пользователя изолированы.

## Как это работает

1. `/start` — короткая настройка: цели давления, часовой пояс, расписание замеров.
2. Бот напоминает утром / днём / вечером → «Записать давление» → значения кнопками → «✅ Записано».
3. «Приняли лекарство?» → «Да» → через выбранное время — вежливый повтор замера.
4. Перед визитом к врачу — «Статистика» и CSV за период.
5. Нужен большой экран — кнопка «Личный кабинет» пришлёт ссылку входа.

При давлении ≥180/110 бот вежливо предложит обратиться к врачу — без диагнозов
и медицинских советов.

## Быстрый старт

```bash
git clone https://github.com/StarLeG/my-bp-diary.git
cd my-bp-diary
uv sync
cp .env.example .env   # заполните BOT_TOKEN и остальные переменные
uv run python -m bot
```

Требуется Python 3.11+ и [uv](https://docs.astral.sh/uv/).

## Переменные окружения

Копируются из `.env.example` в `.env` (файл `.env` не попадает в git):

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather (только env, никогда в коде) |
| `SUPPORT_URL` | ссылка на страницу поддержки; пусто = кнопка скрыта |
| `AUTHOR_CONTACT` | контакт автора; пусто = кнопка скрыта |
| `DB_PATH` | путь к файлу SQLite (по умолчанию `data/bot.sqlite3`) |
| `DEFAULT_TIMEZONE` | часовой пояс по умолчанию (IANA) |
| `LOG_LEVEL` | уровень логирования |
| `WEB_SECRET_KEY` | секрет личного кабинета (сессии и magic link) |
| `CABINET_URL` | base URL личного кабинета; пусто = кабинет не развёрнут |

## Запуск в Docker

Собирается один образ (бот + личный кабинет), запускается через Docker Compose:

```bash
./deploy.sh          # Linux/macOS
.\deploy.ps1         # Windows PowerShell
```

Подкоманды:

| Команда | Действие |
|---|---|
| `up` (по умолчанию) | собрать образ и запустить бота и личный кабинет |
| `https` | то же + HTTPS (Caddy с Let's Encrypt; нужен `CABINET_URL` и DNS) |
| `logs` | логи всех сервисов |
| `ps` | состояние контейнеров |
| `down` | остановить и убрать контейнеры |

Примечания:

- Кабинет слушает только `127.0.0.1:8000`; наружу — через Caddy (HTTPS, профиль `https`).
- Секреты (`BOT_TOKEN`, `WEB_SECRET_KEY`) задаются только в `.env` — в образ и git они не попадают.
- SQLite хранится на общем томе `bot-data` и переживает пересоздание контейнеров.

## Веб-части

- `web/landing/` — статический лендинг: как работает бот, FAQ, кнопка «Открыть в Telegram».
- `web/cabinet/` — личный кабинет (FastAPI + Jinja2): вход по одноразовой ссылке из бота
  (15 минут) или e-mail + пароль (хранится только хеш Argon2id); сессии 7 дней, CSRF,
  ограничение попыток входа. Прямой регистрации «с улицы» нет — привязка только через бота.
  Запускается отдельным процессом (`uvicorn web.cabinet.app:app`) или сервисом Docker Compose;
  HTTPS — за reverse proxy (Let's Encrypt).

## Структура проекта

```
bot/          — бот: хендлеры, сервисы, планировщик напоминаний (APScheduler)
web/landing/  — статический лендинг
web/cabinet/  — личный кабинет (FastAPI, Argon2id, magic link)
tests/        — юнит-тесты (pytest), включая тесты конкурентности
doc/          — ТЗ (TZ.md) и спецификация (SPEC.md)
```

## Тесты

```bash
uv run pytest -q --cov=bot --cov-fail-under=90
```

900 тестов; покрытие `bot/` — 100% строк и веток (требование спецификации: ≥ 90% строк,
бизнес-логика — 100% веток, обязательны тесты конкурентности).

Те же тесты запускаются в GitHub Actions (Python 3.11–3.14) при каждом push и
pull request — статус сборки виден бейджем в начале страницы.
