# Дневник гипертоника

Telegram-бот для ведения дневника измерений артериального давления: быстрая запись за
2 нажатия, напоминания о лекарствах, статистика и CSV для врача. Бесплатный, без рекламы.

## Быстрый старт

```bash
git clone https://github.com/StarLeG/my-bp-diary.git
cd my-bp-diary
uv sync
cp .env.example .env   # заполните BOT_TOKEN и остальные переменные
uv run python -m bot
```

## Переменные окружения

Копируются из `.env.example` в `.env` (файл `.env` не попадает в git):

| Переменная | Назначение |
|---|---|
| `BOT_TOKEN` | токен бота от @BotFather (только env, никогда в коде) |
| `SUPPORT_URL` | ссылка на страницу поддержки; пусто = кнопка скрыта |
| `AUTHOR_CONTACT` | контакт автора; пусто = кнопка скрыта |
| `DB_PATH` | путь к файлу SQLite (по умолчанию `data/bot.sqlite3`) |
| `DEFAULT_TIMEZONE` | часовой пояс по умолчанию (IANA) |
| `LOG_LEVEL` | уровень логирования |
| `WEB_SECRET_KEY` | секрет личного кабинета (сессии и magic link) |
| `CABINET_URL` | base URL личного кабинета; пусто = кабинет не развёрнут |

## Запуск в Docker

Собирается один образ (бот + личный кабинет), запускается через Docker Compose:

```bash
./deploy.sh          # Linux/macOS
.\deploy.ps1         # Windows PowerShell
```

Подкоманды:

| Команда | Действие |
|---|---|
| `up` (по умолчанию) | собрать образ и запустить бота и личный кабинет |
| `https` | то же + HTTPS (Caddy с Let's Encrypt; нужен `CABINET_URL` и DNS) |
| `logs` | логи всех сервисов |
| `ps` | состояние контейнеров |
| `down` | остановить и убрать контейнеры |

Примечания:

- Кабинет слушает только `127.0.0.1:8000`; наружу — через Caddy (HTTPS, профиль `https`).
- Секреты (`BOT_TOKEN`, `WEB_SECRET_KEY`) задаются только в `.env` — в образ и git они не попадают.
- SQLite хранится на общем томе `bot-data` и переживает пересоздание контейнеров.
