**Статус:** ответы на MU1–MU16 получены и утверждены (2026-11-17) — зафиксированы ниже.

Сверено с `doc/SPEC.md`: §6.1 («/start и онбординг», текст приветствия), §6.2 («Главное

## 0. Рамки платформы (в них проектируем)

- **Цвет кнопок теперь возможен** — это меняет прошлое ограничение (в `BOT-UI-UX-QUESTIONS.md`
  цвета не было): у `InlineKeyboardButton` есть поле `style` — `success` (зелёный),
  `primary` (синий), `danger` (красный); без `style` — обычный вид. **Жёлтого/оранжевого
  нет.** Клиенты без поддержки поля показывают обычные кнопки (мягкая деградация).
  aiogram 3.31.0 (в проекте) передаёт `style` без доработок.
- **Высота и кегль кнопок** — по-прежнему клиентские. «Крупная кнопка» = широкая
  (вся строка) + акцент цветом, а не увеличенный шрифт.
- Ширина inline-кнопки — доля строки (1 в ряду ≈ вся ширина). Пара в ряд — компромисс
  по ширине (см. UI3: пары — только короткие альтернативы).
- `callback_data` ≤ 64 байт (§8); кнопки — только inline (принцип «редактируем
  сообщение», §6.2); ReplyKeyboard не используем.
- Бот может закрепить сообщение в личном чате (`pinChatMessage`, права администратора не
  нужны) и снять закреп; удалить может свои сообщения. Устаревшие callback'и — механизм
  U8 «Это сообщение устарело» (§8).

### B. Дубли сообщений в чате

#### MU6. Поведение /start: закреп, редактирование или удаление

Факт: дубли создаёт только `/start` (новое сообщение каждый раз, `start.py`); «В меню»
редактирует на месте и дублей не плодит. Отзыв: «при /start бот должен использовать
editMessageReplyMarkup или удалять старые сообщения; в идеале — закрепить одно сообщение
с главным меню».

Техника вариантов: чтобы редактировать старое сообщение меню, его `message_id` нужно где-то
держать — простой путь: колонка `users.last_menu_message_id` (новое поколение схемы, 13).
Закреп (`pinChatMessage`) в личном чате боту доступен без прав администратора.

- **А** — закреп + редактирование («идеал» отзыва): `/start` редактирует **закреплённое**
  сообщение меню (`users.last_menu_message_id`); если сообщение недоступно (удалено,
  другой аккаунт/устройство) — отправляет новое, закрепляет его и снимает старый закреп.
  «В меню» (`menu:back`) продолжает редактировать сообщение на месте (как сейчас).
  В шапке чата появляется строка «Pinned message» — проверим на стенде, не мешает ли она
  целевой аудитории.
- **Б** — редактирование без закрепа: та же колонка `users.last_menu_message_id`;
  `/start` редактирует запомненное сообщение меню, не найдено — отправляет новое и
  запоминает. Чат чистый, закрепа нет.
