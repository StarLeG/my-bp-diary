# Пост для Telegram о релизе 0.6.0 («Дневник гипертоника»)

Черновик для сообщества `t.me/my_bp_diary` (новости) — на утверждение.
Стиль — по `doc/vk-post.md` и `doc/tg-group/CONTENT.md`: по-русски, дружелюбно,
без канцелярита и маркетинга; «измерение», не «замер»; без медицинских советов;
честные оговорки (известные ограничения 0.6.0 — §15 SPEC). Кнопки процитированы
по `bot/texts.py`. Картинки — демо-кадры из `qa/reports/screens/webp`
(вымышленные данные): например `bot-menu.webp` или новые кадры ленты и
«Добавить запись». Ссылка на бота — с `?start=landing`.

---

```
Обновление 0.6.0: теперь это дневник, а не только цифры 📓

Раньше бот умел записывать давление. С этого обновления он умеет вести дневник целиком — с контекстом, который врачу важен не меньше самих цифр.

➕ Добавить запись — семь типов:
💊 Приём лекарства — статус и время, даже если давление не мерили.
🚶 Прогулка / активность — сколько минут гуляли.
🥗 Питание — солёное, кофе, алкоголь: три касания.
😐 Стресс / самочувствие — с коротким описанием.
😴 Сон — «мало спал / нормально / много».
📝 Заметка — что угодно, что хочется запомнить.

Запись давления стала короче:
✏️ Один экран вместо пяти: систолическое, диастолическое и пульс — тремя полями, с кнопками-цифрами.
⌨️ Или одной строкой в чат: «120/80 72» — бот сам разберёт.
• Пульс можно не вводить — просто оставьте поле пустым.

Рядом с каждым измерением:
➕ Фактор — отметить соль, кофе, алкоголь, стресс или недосып прямо в сводке.
💊 Лекарство — быстрая отметка приёма; бот напомнит повторить измерение через нужное время.
✏️ Изменить — поправить цифры, если ошиблись.

📖 «Дневник за сегодня» — теперь лента всего дня: измерения, лекарства и события по времени, с фильтрами «Давление» / «Лекарства» / «Факторы» / «Другое». Событие можно открыть, поправить или удалить.

Честные оговорки: события дневника пока не попадают в выгрузку CSV/PDF и личный кабинет — добавим в следующих обновлениях. Старые записи и напоминания работают как раньше, крупный режим тоже на месте.

Попробовать: https://t.me/my_bp_diary_bot?start=landing
Сайт и руководство: https://bp-diary.electroman.by/

Как вам новый дневник? Пишите в комментариях — что удобно, что мешает. Обратная связь реально помогает: половина функций выше появилась из ваших писем.
```
