## Шаг 1. Схема БД: `diary_events` (поколение 11)

- `SCHEMA_VERSION = 11`; миграция при старте: `CREATE TABLE diary_events` + индексы

  (FK users.id), `type: Mapped[str]` (CHECK food/stress/sleep/activity/note),

  `payload: Mapped[Optional[str]]` (JSON), `measurement_id: Mapped[Optional[int]]`
  (FK measurements.id, `ondelete="SET NULL"`), `created_at: Mapped[datetime]`.

  пересборки; CHECK типа; удаление измерения снимает привязку, событие остаётся;

## Шаг 2. Сервис событий: `bot/services/events.py` (новый)

Сигнатуры (async, `AsyncSession` первым аргументом после self-модуля; канон
`bot/services/measurements.py`):
- `create_event(session, user, type_: str, moment: datetime, *, note: str | None = None,
  payload: dict | None = None, measurement_id: int | None = None) -> DiaryEvent`;
- `create_factor_events(session, user, measurement_id: int, marks: set[str], moment)
  -> list[DiaryEvent]` — одна транзакция: `salt/coffee/alcohol` → одно событие `food`
  с `marks`, `stress` → `stress{variant:stress}`, `sleep` → `sleep{rating:little}`;
  идемпотентно (§7.2): `INSERT … WHERE NOT EXISTS` по `(user_id, measurement_id,
  type, payload)` — повторное «Готово» дописывает недостающие; `marks` — отсортированы,
  JSON канонический (детерминированная сериализация, иначе двойной тап даст дубль);
- `update_event(session, user, event_id, …) -> DiaryEvent | None`, `delete_event(...)`
  -> bool — проверка владельца (§7.1), чужое — как отсутствующее;
- `events_for_day(session, user, day: date) -> list[DiaryEvent]`;
- `upsert_sleep(session, user, day, rating) -> DiaryEvent` — одна оценка на локальные
  сутки: есть событие тех суток — обновить его (условная вставка, §7.2);
- `event_payload(type_, **fields) -> dict` — валидация полей payload (канон §4.18).
- Валидация времени события: ≤ текущего, в пределах 24 часов (C13) — общий хелпер
  `validate_event_moment(raw_time, tz, now)` в `bot/schemas.py`.
- Тесты (`tests/test_services_events.py`): типы и payload, владелец, sleep-обновление,
  идемпотентность факторов (двойной тап, конкурентно — `tests/test_concurrency.py`).
