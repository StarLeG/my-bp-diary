# Почта noreply@electroman.by: обращение в хостинг и записи DNS

Контекст: релиз 0.4.11 отправляет врачу письмо со ссылкой доступа через SMTP своего домена (SPEC §21). С прод-сервера `185.23.239.253` SMTP-порты почтового сервера `mail.electroman.by` (93.84.119.241) недоступны — 465, 587, 25, 26, 2525 обрываются по таймауту, при этом 80/443 открыты (проверено 2026-11-09). На проде `SMTP_HOST` пока пуст, письма не уходят — пациент получает ссылку для пересылки.

---

## Письмо в поддержку хостинга

> Здравствуйте! Нужен ответ специалиста, не автоматический. Аккаунт cPanel с доменом electroman.by.
>
> С нашего сервера 185.23.239.253 не открывается ни один SMTP-порт на mail.electroman.by (93.84.119.241): 465, 587, 25, 26, 2525 — соединение обрывается по таймауту, при этом 80/443 доступны. Это фильтр на вашей стороне.
>
> Просим добавить IP **185.23.239.253** в белый список для SMTP с авторизацией (порт 465, ящик noreply@electroman.by). Объём — единицы писем в день: уведомления врачам от сервиса «Дневник гипертоника».
>
> Если открыть доступ для внешних IP нельзя — напишите, пожалуйста, прямо, чтобы мы подключили другой способ отправки.

## Записи DNS (панель domain.by)

Обе записи — тип **TXT**, TTL по умолчанию, кавычки вокруг значения не ставить.

| Запись | Имя (хост) | Значение |
|---|---|---|
| DMARC | `_dmarc` | `v=DMARC1; p=none; rua=mailto:info@electroman.by` |
| DKIM | `default._domainkey` | значение из cPanel: **Email** → **Email Deliverability** → `electroman.by` → **Manage** → блок **DKIM** → поле **Value** (начинается с `v=DKIM1; k=rsa; p=…`) |

- Если панель сама подставляет `.electroman.by`, имя вводится коротко (как в таблице); если требует полное — `_dmarc.electroman.by` и `default._domainkey.electroman.by`.
- SPF уже есть и правильный (`v=spf1 ip4:93.84.119.241 … +a +mx … ~all`) — вторую SPF-запись не добавлять.
- MX и A-записи не трогать.

## После ответа хостинга

- **Доступ открыт** — вернуть в `.env` на проде `SMTP_HOST=mail.electroman.by` (сейчас записан в комментарии `SMTP_HOST_PENDING`), `./restart.sh`, отправить тестовое письмо на info@electroman.by.
- **Отказ** — решение заказчика: внешний почтовый сервис (Brevo, Unisender Go и т.п., отправитель остаётся `noreply@electroman.by`, вариант Б из вопроса E1 в `doc/DOCTOR-INVITE-QUESTIONS.md`) или оставить без писем.
