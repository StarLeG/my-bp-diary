## Допущения на подтверждение

1. Пороги и цвета — из `chart_zones.py` (один источник с графиками), зона строки считается на сервере; персональная цель пользователя не влияет (как у графика).
2. Цвет — та же полупрозрачная заливка, что у зон графика; при наведении строка остаётся читаемой. На узких экранах подсвечивается карточка записи целиком (или её ячейки — по Z1).
3. Цвет — не единственный носитель смысла: цифры в строке остаются как есть; у строки — `title` с зоной («САД ≥ 140»), для скринридеров.
4. Только информационная подсветка, без текстов-диагнозов (как у графиков, §16.2).
5. Версия — PATCH (0.4.6).

1. SPEC §16.2 (и §21 по Z3) — по ответам.
