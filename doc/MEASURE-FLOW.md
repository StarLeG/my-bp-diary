# Запись в дневник (0.6.0) — полный функционал

Справка по флоу записи: «Записать давление», «➕ Добавить запись» и лента дневника.
Источник истины — `doc/SPEC.md` (§6.3 — запись давления, §6.14 — типы записей,
§6.4 — лента, §6.7 — приёмы и повтор замера, §7.2 — конкурентность, §8 —
callback_data, §9 — валидация); здесь — как это работает в коде. Решения и
протокол переработки — `doc/MEASURE-REDESIGN-QUESTIONS.md`, план —
`doc/MEASURE-REDESIGN-PLAN.md`.

Код: `bot/handlers/measure.py` (калькулятор, сводка), `bot/handlers/events.py`
(типы записей), `bot/handlers/diary.py` (лента), `bot/services/events.py`
(события), `bot/keyboards.py`, `bot/texts.py`, `bot/schemas.py`.

## 1. Точки входа

| Callback | Откуда | Что открывает |
|---|---|---|
| `menu:measure` | «Записать давление» (меню, пустой дневник), `rem:write:{slot}:{д}`, `rem:now` | сразу калькулятор (прямой вход, R1 = Б) |
| `add:menu` | «➕ Добавить запись» (меню, лента) | экран выбора типа записи |
| `add:bp` | «Давление и пульс» из меню типов | калькулятор |
| `add:med` | «Приём лекарства» | фасад над `medication_logs` (§5) |
| `add:walk` / `add:food` / `add:stress` / `add:sleep` / `add:note` | остальные типы | флоу события (§6) |
| `m:edit`, `m:arch:edit` | «✏️ Изменить» | калькулятор с текущими значениями записи |

## 2. Калькулятор «САД | ДАД | Пульс» (§6.3)

Один экран: шапка «🩺 Давление и пульс», три поля, итог `135/85 · пульс 72`.
Кнопки итога (`m:field:{sys|dia|pulse}`) переключают фокус; активное поле —
«▸ », набор показан в нём.

| Кнопка | Callback | Действие |
|---|---|---|
| 0–9 | `m:key:{n}` | цифра в буфер активного поля (`m_buf`, ≤ 3 цифр) |
| C / ⌫ | `m:key:clear` / `m:key:bksp` | очистить / стереть цифру активного поля |
| Готово | `m:key:ok` | коммит буфера → валидация → сохранение |
| Изменить | `m:reset` | сброс всех полей, фокус в систолическое |
| Отмена | `m:cancel` | в главное меню (черновик сбрасывается) |

- Пустой пульс — `pulse = NULL` (кнопки «Пропустить» нет; при правке пустой
  пульс очищает прежний).
- «Готово» и переключение поля сначала коммитят буфер, затем валидируют (C9).
- **Быстрая строка**: любое сообщение — `120/80 72`, `120/80/72` или `120/80`
  (позиции 1/2/3; сепараторы `/` и пробел, лишние пробелы и ведущие нули —
  норма; точка/запятая — «Например: 120/80 72»). Строка заполняет все поля,
  фокус — на пульс; сохранение — только «Готово». Одиночное число — в активное
  поле.
- Валидация: САД 70…260, ДАД 40…160 (строго ниже САД), пульс 30…220 (§9).

## 3. Сохранение и сводка (§6.3)

INSERT текущим моментом; дубль за минуту — «Это давление уже записано» (§7.2).
Сводка — одна строка `✅ 135/85, пульс 72` (без пульса — `✅ 135/85`; правка —
`✅ Обновлено: …`; архив — `✅ … · за 12.03.2025, 08:00`). При ≥ 180/110 (кроме
архива) — вторая строка «Эти значения стоит обсудить с врачом на ближайшем
приёме.»

Кнопки сводки: «✏️ Изменить» · «➕ Фактор» · «💊 Лекарство» · «Самочувствие» ·
«📝 Заметка» · «Готово» (в меню).

- **➕ Фактор** (`m:fact:*`) — метки «Солёное / Кофе / Алкоголь / Стресс /
  Недосып» → события `diary_events` с привязкой к измерению: соль/кофе/алкоголь —
  одно событие `food` с набором меток, стресс — `stress`, недосып — `sleep`;
  момент события — момент измерения; идемпотентно.
- **💊 Лекарство** (`m:med`) — привязка к записи есть → «💊 Принято: …»
  (чтение) + «➕ Добавить ещё»; нет → мультивыбор «Какие лекарства приняли?»
  (пустой выбор, «· сегодня ✓» у принятых); «Готово» пишет `medication_logs` и
  связи, планирует повтор замера (один на измерение). Без лекарств — подсказка
  «Напоминать, какие лекарства принимать?» один раз (`users.meds_ask_shown_at`).
- **Самочувствие** — 4 варианта `feeling` записи (не путать с событием
  «Стресс / самочувствие»).
- **📝 Заметка** — ≤ 500 символов.

## 4. Правка последней записи (§6.3)

«✏️ Изменить» (сводка / «Дневник за сегодня») — «последняя» резолвится на
сервере; калькулятор открывается с текущими значениями. Сохранение — UPDATE
трёх значений без смены времени; дубль-проверка не применяется. У архива
правка — по id из контекста («m:arch:edit»).

## 5. «Приём лекарства» — фасад (§6.7)

Выбор приёма («Лозартан 50 мг · утро») → статус «Принял / Пропустил /
Частично» → время («Сейчас» / «Другое» — `timestamp` записи, 24 часа; слот не
меняется) → запись в `medication_logs` с дедупом за сутки. При `taken` —
повтор замера (один активный на пользователя). Пустой список — «Сначала
добавьте лекарства в настройках» + «Добавить».

## 6. Типы событий (§6.14)

События пишутся в `diary_events`; момент — «сейчас» или «Другое» (`ЧЧ:ММ`,
последние 24 часа). После сохранения — «✅ Записано» + «✏️ Изменить» /
«🗑 Удалить» (с подтверждением) / «➕ Добавить ещё» / «В меню».

| Тип | Флоу | Payload |
|---|---|---|
| Прогулка (`activity`) | «10/20/30/60 минут» → время | `duration_min` |
| Питание (`food`) | **один экран**: метки + radio «🕓 Сейчас / 🕓 Другое время» + «Готово» | `marks[]` |
| Стресс (`stress`) | «Что чувствуете?» → текст (для «Другое» обязателен) → время | `variant` + `note` |
| Сон (`sleep`) | «Мало спал / Нормально / Много» (без времени; повтор за сутки обновляет) | `rating` |
| Заметка (`note`) | текст → время | текст в `note` |

Правка события — перезапуск флоу с текущими значениями (время — «🕓 Оставить
{момент}» / «Другое»); у сна — обновление оценки.

## 7. Лента «Дневник за сегодня» (§6.4)

UNION измерений, приёмов и событий по времени. Строки — кнопки: событие →
карточка (правка/удаление), приём → «Только просмотр», измерение → ничего.
Чипы-фильтры «Давление / Лекарства / Факторы / Другое» (тап по активному —
сброс в «Все»); «Всего записей: N» — по текущему фильтру.

## 8. Идемпотентность и совместимость

- Debounce 1.5 с — только пишущие кнопки (`m:key:ok`, `add:time:now`,
  `add:sleep:*`, `ev:save:*`, `ev:del:*:ok`, …); буфер калькулятора, чекбоксы и
  чтение — каждое нажатие; остальное — throttle 1 с.
- Старые кнопки (до 0.6.0) без черновика → главное меню; `m:key:skip` — legacy.
- Дедуп давления за минуту, повтор замера — по `m_id` (один на измерение),
  `ensure_remeasure(None)` — один активный на пользователя.
